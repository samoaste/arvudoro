# Privacy

Arvudoro collects no personal data.

- **No account, no telemetry, no analytics, no ads.**
- **Local only.** Settings and your history (completed focus sessions and
  exercises) are stored on your computer, in the app's data folder:
  - Linux: `~/.local/share/com.arvucore.arvudoro/`
  - macOS: `~/Library/Application Support/com.arvucore.arvudoro/`
  - Windows: `%APPDATA%\com.arvucore.arvudoro\`

  You can erase the history at any time in Stats → Clear history, or by
  deleting that folder.
- **One network request.** Once a day the app downloads
  `manifest.json` from this project's GitHub Releases to check for updates.
  That request goes to GitHub and carries nothing about you beyond what any
  web request does (your IP address and the app's user agent); see
  [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- **Links you click** (like the author's GitHub profile) open in your browser.
