# Security policy

## Supported versions

Only the latest release receives fixes. Installed apps update themselves.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub's security advisories](https://github.com/samoaste/arvudoro/security/advisories/new)
or by email to samoaste@gmail.com.

Include what you found, how to reproduce it and the affected version and OS.
You'll get a reply within a week, and a fix or mitigation plan as soon as the
issue is confirmed. You'll be credited in the release notes unless you prefer
otherwise.

Areas that matter most: the auto-update path (manifest and archive
verification), the page ↔ backend bridge, and anything that reads or writes
files.
